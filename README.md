# NASA_Info: ติดตามพื้นที่ประเทศไทยจากดาวเทียม

ระบบแผนที่สำหรับดูสภาพพื้นที่จากภาพดาวเทียม เน้น **น้ำท่วม**, **ฝุ่น PM** และ **ฝน**
ดึงข้อมูลจาก NASA และหน่วยงานไทยแบบสด ไม่ต้องใช้ API key

**เปิดใช้งาน:** https://thtpk.github.io/NASA_Info/

## ความสามารถ

| โหมด | ชั้นข้อมูล | แหล่งข้อมูล |
|---|---|---|
| 🌊 น้ำท่วม | พื้นที่น้ำท่วมรายวัน (MODIS / VIIRS), ผิวน้ำ 30 ม. จากเรดาร์ Sentinel-1 (OPERA), เหตุการณ์น้ำท่วม | NASA GIBS, NASA EONET |
| 💨 ฝุ่น PM | PM2.5 สถานีภาคพื้นดิน, ความหนาฝุ่นละออง (AOD), จุดความร้อน/ไฟป่า | Air4Thai (กรมควบคุมมลพิษ), NASA GIBS |
| 🌧️ ฝน | ฝนรายวันและราย 30 นาที (IMERG), เมฆอินฟราเรด Himawari (ทุก 10 นาที), ความชื้นในดิน (SMAP) | NASA GIBS |
| 🏭 พื้นที่ผิดปกติ | พืชพรรณเสียหายผิดปกติ 30 ม. (OPERA DIST-ALERT), ภาพสีจริง 30 ม. Sentinel-2 / Landsat (HLS) สำหรับเทียบก่อน/หลัง | NASA GIBS |

- **คลิกจุดใดก็ได้** เพื่อดูค่าจริงของพื้นที่ (อ่านค่าจากสีของภาพดาวเทียมผ่าน colormap ของ GIBS) พร้อมกราฟย้อนหลัง 14 วัน
- เลือกวันที่ย้อนหลัง และเล่นภาพแบบ timelapse ได้
- ค้นหาจังหวัด/อำเภอ, ปรับความทึบ, ซ่อน/แสดงประเภทข้อมูล (เช่น พื้นที่เมฆบัง)

## รันในเครื่อง

```bash
python server.py
```

แล้วเปิด http://localhost:8770/monitor/ (ใช้ข้อมูลสดผ่าน proxy ใน `server.py`)

## GitHub Pages

`.github/workflows/pages.yml` รัน `update_data.py` เพื่อดึงข้อมูล PM2.5 และวันที่ล่าสุดของชั้น GIBS
แล้ว deploy ขึ้น Pages ทุกชั่วโมง (ต้องตั้ง **Settings → Pages → Source = GitHub Actions**)

## ไฟล์อื่นในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `eonet_thailand_floods.py` | ดึงเหตุการณ์น้ำท่วมในไทยจาก EONET เป็น CSV |
| `make_flood_map.py`, `make_flood_globe.py` | สร้างแผนที่ 2 มิติ / ลูกโลก 3 มิติ จาก CSV |
| `nasa_config.py` | อ่าน `NASA_API_KEY` จากไฟล์ `.env` (สำหรับ API ที่ต้องใช้ key เช่น NeoWs, DONKI) |
| `gibs_layers.csv` | รายชื่อชั้นข้อมูล GIBS ทั้งหมด 1,330 ชั้น |

API key ให้เก็บในไฟล์ `.env` (`NASA_API_KEY=...`) ซึ่งไม่ถูก commit ขึ้น git

## ข้อจำกัด

- AOD คือความหนาของฝุ่นในบรรยากาศทั้งชั้น **ไม่ใช่ค่า PM2.5** โดยตรง
- PM2.5 จากสถานีเป็นค่าล่าสุดเท่านั้น ไม่เปลี่ยนตามวันที่ที่เลือก
- ภาพรายวันบางชั้นล่าช้า 1–5 วัน ระบบจะใช้วันล่าสุดที่มีและแจ้งไว้
